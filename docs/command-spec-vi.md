# vi コマンド仕様一覧(vi.1より抽出)

出典: `vi.1`(Berkeley版 vi.1 6.1 (4/29/85) + Gunnar Ritter改訂版, troff形式)。
`vi`/`view`/`edit`は同一コードで、`view`は読み取り専用起動、`vedit`は初心者向けオプション調整版。
`ex`コマンドの大半は`:`接頭辞でvisualモードからも呼べる(詳細は`docs/command-spec-ex.md`)。

## 0. 起動オプション・環境変数・関連ファイル

### コマンドライン引数

| オプション | 意味 |
|---|---|
| `-c command` / `+command` | 編集開始時に指定コマンドを実行 |
| `-l` | LISP編集向けの特殊モードで開始 |
| `-r [filename]` | 引数なし: リカバリ可能なファイル一覧を表示して終了。`filename`指定: そのリカバリ用一時ファイルを復元モードで開く |
| `-L` | `-r`(引数なし)と同じ |
| `-R` | 読み取り専用で開く |
| `-s` / `-` | スクリプトモード。対話的フィードバック無効化、`EXINIT`/`.exrc`は処理しない |
| `-t tagstring` | tagsファイルを読み、指定タグの位置で編集開始 |
| `-V` | 端末以外から入力される場合、コマンド入力をstderrへエコー |
| `-w size` | visualモードの編集ウィンドウサイズ指定 |

### 環境変数

`COLUMNS`, `EXINIT`(起動時実行コマンド。設定時は`.exrc`は無視), `HOME`(`.exrc`探索先),
`LANG`/`LC_ALL`, `LC_CTYPE`(バイト→文字マッピング、大小変換、正規表現の文字クラス),
`LC_MESSAGES`, `LINES`, `NLSPATH`, `SHELL`(外部コマンド実行に使用), `TERM`

### 関連ファイル

`/usr/libexec/expreserve`, `/usr/libexec/exrecover`, `/etc/termcap`, `$HOME/.exrc`,
`/var/tmp/Ex<nnnnnnnnnn>`(編集用一時ファイル), `/var/tmp/Rx<nnnnnnnnnn>`(名前付きバッファ用
一時ファイル), `/var/preserve`(保存ディレクトリ)。`docs/terminal-and-support.md`の
リカバリ機構調査と対応。

## 1. カーソル移動(モーション)

### 文字単位

| キー | 動作 |
|---|---|
| `h` / `^H` / BS / 左矢印 | 左へ1文字 |
| `l` / SPACE / 右矢印 | 右へ1文字 |
| `j` / `^J` / `^N` / 下矢印 | 下へ1行(同じ列を維持、なければ最も近い列) |
| `k` / `^P` / 上矢印 | 上へ1行 |
| `0` | 現在行の先頭文字へ(数値入力の一部としても使われる: `1`-`9`の後には桁として解釈) |
| `^` | 現在行の最初の非空白文字へ |
| `$` | 現在行の末尾へ。カウント`n`で`n`行先の行末へ(`2$`は次の行の末尾) |
| `|` | カウントで指定した桁(列)へ移動 |
| `+` / CR | 次の行の最初の非空白文字へ(カウントで複数行) |
| `-` | 前の行の最初の非空白文字へ |

### 単語単位

| キー | 動作 |
|---|---|
| `w` | 次の単語の先頭へ |
| `b` | 単語の先頭へ戻る(単語=英数字列 or 特殊文字列) |
| `e` | 次の単語の末尾へ |
| `W` | 次の「WORD」(空白区切りの塊)の先頭へ |
| `B` | 前の「WORD」の先頭へ戻る |
| `E` | 次の「WORD」の末尾へ |

### 行・画面単位

| キー | 動作 |
|---|---|
| `G` | 指定行番号へ(カウントなしはファイル末尾) |
| `H` | 画面先頭行(カウントでn行目)の最初の非空白文字へ |
| `M` | 画面中央行の最初の非空白文字へ |
| `L` | 画面最終行(カウントで下からn行目)の最初の非空白文字へ |

### 文単位・段落単位・セクション単位

| キー | 動作 |
|---|---|
| `(` | 文の先頭へ戻る(`lisp`オプション時はS式の先頭)。文は`. ! ?`+空白2つ or 行末で終わる |
| `)` | 次の文の先頭へ |
| `{` | 段落の先頭へ戻る(`paragraphs`オプションのマクロ、空行、セクション境界で区切られる) |
| `}` | 次の段落の先頭へ |
| `[[` | 前のセクション境界へ(`sections`オプションのマクロ、`^L`、`{`で始まる行) |
| `]]` | 次のセクション境界へ |
| `%` | 対応する括弧(`()`/`{}`)へジャンプ |

### 文字検索(行内)

| キー | 動作 |
|---|---|
| `f` | 次に現れる指定1文字の位置へ(前方) |
| `F` | 指定1文字の位置へ(後方) |
| `t` | 次の指定文字の直前まで(前方、オペレータと併用しやすい) |
| `T` | 指定文字の直後まで(後方) |
| `;` | 直前の`f`/`F`/`t`/`T`を繰り返す |
| `,` | 直前の`f`/`F`/`t`/`T`を逆方向に繰り返す |

### マーク・前回位置

| キー | 動作 |
|---|---|
| `` ` `` + `` ` `` | 直前のコンテキスト(行頭)へ戻る |
| `` ` `` + 文字 | マーク位置(正確な列)へ |
| `'` + `'` | 直前のコンテキスト(行頭)へ戻る |
| `'` + 文字 | マーク位置の最初の非空白文字へ |
| `m` + 文字(`a`-`z`) | 現在位置をマークに記録 |

いずれもカウント指定可能(多くは「n回繰り返す」の意味)。

## 2. 編集オペレータ

| キー | 動作 |
|---|---|
| `d` | 後続オブジェクト(モーション)を削除。複数行にまたがる場合は番号付きバッファに退避 |
| `c` | 後続オブジェクトを変更(削除して挿入モードへ、ESCで確定) |
| `y` | 後続オブジェクトを無名バッファへヤンク。`"x`で名前付きバッファ指定可 |
| `<` | 後続オブジェクトを`shiftwidth`分左シフト |
| `>` | 後続オブジェクトを`shiftwidth`分右シフト |
| `!` | 後続オブジェクトを外部コマンドでフィルタ処理(`!}fmt`<CR>のように使う) |
| `=` | LISP向け再インデント(`lisp`+`autoindent`相当) |

**組み合わせ規則**:
- オペレータを2回重ねる(`dd`, `cc`, `yy`, `<<`, `>>`, `!!`)と行全体が対象になる。
- カウントはオペレータ側・モーション側どちらに付けても等価(`3dw` == `d3w`)。
- `!`だけは例外的に、`!!`+前置カウントで行数指定、それ以外はモーション側にカウントが渡る。
- 1行の一部だけが対象の場合、変更前の最後の文字位置に`$`が表示される(`c`/`s`)。

## 3. 挿入コマンド

| キー | 動作 |
|---|---|
| `i` | カーソル位置の前に挿入開始 |
| `a` | カーソル位置の後に挿入開始(`A`は`$a`の別名) |
| `I` | 行の先頭(`^i`相当)に挿入開始 |
| `A` | 行末に追記(`$a`の別名) |
| `o` | 現在行の下に新規行を開いて挿入 |
| `O` | 現在行の上に新規行を開いて挿入 |
| `R` | 上書き(オーバーレイ)入力。ESCで終了 |
| `s` | カーソル下の1文字を変更(カウントでn文字)。`c`同様に`$`マーク |
| `S` | 行全体を変更(`cc`の別名)。カウントでn行 |
| `C` | 行の残りを変更(`c$`の別名) |
| `r` | カーソル位置の1文字を置換(カウントでn文字を同じ文字に置換)。改行も指定可 |

挿入中の特殊操作: `^H`(直前の入力文字を取り消し表示は残す), `^W`(単語単位で戻る),
`^T`(autoindent時にshiftwidth分のインデント挿入), `^D`(autoindentの空白をバックタブ),
`^V`/`^Q`(次の1文字をエスケープしてリテラル入力), `^@`(直前の挿入内容(最大128文字)を再挿入して終了)。

## 4. 検索・置換

| キー | 動作 |
|---|---|
| `/` | 前方検索。パターン入力後CRで検索開始。末尾に`/`+オフセット(`+n`/`-n`)を付けると行単位動作を強制 |
| `?` | 後方検索(`/`と同様) |
| `n` | 直前の`/`または`?`を繰り返す |
| `N` | 直前の`/`または`?`を逆方向に繰り返す |
| `&` | `:&`(直前の`:s`を繰り返す)の別名 |

検索の注意点: 既定でファイル末尾から先頭へラップアラウンドする。`/`中で`^`は行頭固定、`$`は行末固定。
`nomagic`が設定されていない限り、`. [ * ~`はメタ文字として解釈される(エスケープには`\`)。
置換コマンド`:s///`自体は`ex`コマンド体系(`docs/command-spec-ex.md`参照)。

## 5. マーク・レジスタ(名前付きバッファ)

- `m` + `a`-`z`: 現在位置をマークとして記録。
- `` ` `` / `'`: マーク・前回位置への移動(上記1章参照)。オペレータと併用時、`` ` ``は正確な文字位置、
  `'`は行全体が対象になる。
- `"` + `a`-`z` または `1`-`9`: 直後のオペレータ(`d`/`y`)や`p`/`P`が使う名前付きバッファを指定する
  プレフィックス。
- バッファ`1`-`9`: 削除されたテキストが自動的に退避される(番号付き、直近の削除ほど若い番号)。
- バッファ`a`-`z`: ユーザーが明示的に指定して使う汎用バッファ。
- `p`: カーソルの後/下にバッファ内容を貼り付け(行単位で削除されたものは行として、行内の一部なら
  文字として挿入)。
- `P`: カーソルの前/上に貼り付け。
- `Y`: 現在行を無名バッファへヤンク(`yy`の同義語)。カウントでn行。

## 6. 繰り返し・アンドゥ

| キー | 動作 |
|---|---|
| `.` | 直前にバッファを変更したコマンドを繰り返す。カウントを与えると繰り返し先のコマンドのカウントとして渡す(`2dw`の後`3.`は3語削除) |
| `u` | 直前の変更をアンドゥ。連続で押すと2状態を交互に切り替える(=自分自身の逆操作) |
| `U` | 現在行をユーザーが変更を始める前の状態に復元(行全体の巻き戻し) |

---

## 7. 画面制御

| キー | 動作 |
|---|---|
| `^F` | 前方(下方向)へ1ウィンドウスクロール。カウントで繰り返し |
| `^B` | 後方(上方向)へ1ウィンドウスクロール |
| `^D` | 半ウィンドウ下スクロール。カウントで行数指定、次回`^D`/`^U`のデフォルトとして記憶 |
| `^U` | 半ウィンドウ上スクロール(`^D`の逆、カウントを共有) |
| `^E` | 現在行を動かさず画面を1行下にずらす(下にもう1行見せる) |
| `^Y` | 現在行を動かさず画面を1行上にずらす |
| `^L` | 画面クリア&再描画(フォームフィード文字) |
| `^R` | 画面再描画(論理行の`@`のみの行を除去。hardcopy端末では現在行を再タイプ) |
| `z` + CR/`.`/`-` | 現在行を画面の上端/中央/下端に来るよう再描画。前置カウントで中央に置く行番号を指定、`z`直後のカウントで再描画時のウィンドウサイズを指定可 |
| `^G` | `:f`<CR>相当。ファイル名・変更有無・現在行番号・総行数・進捗%を表示 |

## 8. モード切替

| キー | 動作 |
|---|---|
| ESC | 未完成コマンドのキャンセル、挿入モード終了、下端行入力の終了 |
| `Q` | `ex`コマンドモードへ移行(行単位でコマンドを実行、`:`はプロンプトとして自動表示) |
| `:` | 下端行に`ex`コマンドを1つ入力して実行(誤って押した場合はDEL/RUBで復帰可) |
| `^Z` | (Unixがサポートすれば)エディタを一時停止しシェルへ戻る。`:stop`<CR>と同じ |
| `^^` | `:e #`<CR>相当。直前に編集していたファイルへ戻る |
| `^]` | カーソル位置以降の単語をタグとして検索(`:ta`<CR>相当) |

## 9. マクロ・シェル実行・その他

| キー | 動作 |
|---|---|
| `@` | マクロ文字(6.9節)。キル文字と衝突する場合は`\`でエスケープが必要な場合がある |
| `#` | ファンクションキーのない端末で番号によりファンクションキーを代替するマクロ文字。挿入モードで消去文字と衝突する場合あり |
| `!` (演算子、再掲) | 外部コマンドでオブジェクトをフィルタ処理。`:r`(ファイル/コマンド出力読み込み)、`:!`(単純実行)は`ex`側 |
| `~` | カーソル位置からカウント分の文字の大小を反転(英字以外は無視) |
| `X` | カーソル位置の直前の文字を削除(カウントで複数、現在行のみ) |
| `x` | カーソル位置の文字を削除(カウントで複数、現在行のみ) |
| `J` | 次行を現在行に結合(単語間は空白1つ、`.`の後は2つ、次行先頭が`)`なら空白なし)。カウントで結合行数指定 |
| `ZZ` | 変更があれば保存して終了(`:x`<CR>と同じ) |
| `^C` / `^A` / `^K` / `^O` / `^X` / `*` / `V` / `g` / `K` / `q` / `v` / `^\` / `_` | 未使用(Unused、将来拡張用の予約枠) |
| `^?`(DEL) | エディタへの割り込み、コマンド受付状態へ戻す |

**未対応(known limitation, NOTESセクションより)**:
- `:source`をvisualモード中の`:`から呼ぶと`:append`/`:change`/`:insert`は使えない(複数行入力を
  `:`エスケープで与えられないため)。`:global`上でこれらを使うには`Q`で`ex`モードへ移行する必要がある。
- `^T`によるソフトタブは`autoindent`直後にしか効かない。
- インテリジェント端末でも左右シフトは挿入/削除文字操作を使わない。
- `wrapmargin`は出力カラムを見て折り返すため、長い単語がマージンを超えるとだまされる(折り返されない)
  ことがある。
- タブがある行の挿入/削除はインテリジェント端末で遅くなることがある。

## Swift版互換性チェックリストへの示唆

- モーション(1章)とオペレータ(2章)は明確に直交した2つの分類であり、Swift版でも
  `Motion`プロトコル/`Operator`プロトコルのような形で分離設計するのが素直(`docs/vi-mode.md`の
  「モーション+オペレータの2段階デコード」ともここでの整理が対応する)。
- カウントの伝播規則(オペレータ側/モーション側どちらに付けても等価、`!`は例外)は仕様として
  明文化されているため、ゴールデンテストの対象にしやすい。
- `.`(リピート)は「直前にバッファを変更したコマンド」を対象にする、という定義がある。単なる
  キーストローク再生ではなく「最後の変更コマンド」の記録が必要。
- `:source`の制約のように、原典が意図的に持つ制限はSwift版で無理に解消せず「既知の制限」として
  明示的にドキュメント化するかどうかは実装時に判断する。
